# 트러블슈팅: AI 챗봇 주문서 양식 추출 오류 핫픽스 (JSON Schema 파싱)

## 문제 현상
사용자가 AI 챗봇을 통해 케이크를 문의할 때, 챗봇이 사장님이 설정해 둔 주문서 양식(예: "케이크 사이즈", "장식 유무" 등)을 물어보지 않고 "케이크의 종류(type)와 상세한 요청사항(properties)을 말씀해 주세요"와 같이 비정상적인 시스템 키값을 질문하는 현상이 발생했습니다.

## 원인 분석
최근 사장님 앱(FE-Owner)의 주문서 양식 저장 구조가 개편되면서 원인이 발생했습니다.
- **기존 포맷**: `{"templates": [{"label": "케이크 사이즈"}]}`
- **변경 포맷 (JSON Schema)**: `{"type": "object", "properties": {"field_xxx": {"label": "케이크 사이즈"}}}`

AI 서버(`main.py`)의 프롬프트 생성 로직은 기존처럼 `"templates"` 키가 없으면 `list(request.schema_json.keys())`를 통해 최상위 키값들만 추출하도록 되어 있었습니다.
변경된 포맷에서는 최상위 키값이 `"type"`과 `"properties"`였기 때문에, AI가 이를 '질문해야 할 항목'으로 착각하게 되었습니다.

## 해결 방법
AI 서버(`main.py`)의 `schema_json` 처리 로직을 다음과 같이 수정했습니다:
1. `request.schema_json`에 `"properties"` 키가 존재하는지 확인합니다.
2. `"properties"` 내부의 각 필드 객체를 순회하며 `.get("label")` 값을 추출하여 `labels` 리스트를 구성하도록 조건(`elif`)을 추가했습니다.

이를 통해 AI가 다시 정상적으로 "케이크 사이즈", "장식" 등의 실제 라벨을 기준으로 고객에게 질문을 던질 수 있게 되었습니다.
